MADURAI HIRANYA TRAVELS — LOCAL IMAGE SETUP
============================================

The website HTML and CSS already refer to images using local paths in the
existing images/ folder. The logo and favicon are included.

To download the remaining travel photos:
1. Extract this ZIP.
2. Open the madurai-hiranya-travels folder.
3. Double-click download_images.bat, or run: python download_images.py
4. Keep the downloaded files in the existing images/ folder.

Internet access is required for the one-time download. After the images have
been downloaded, the website displays them from local files rather than
loading those photos from external image URLs.

Expected photo files:
hero-van-road.jpg, mountain-road.jpg, local-city.jpg, outstation-hills.jpg,
tourist-car.jpg, airport.jpg, custom-tour.jpg, scenic-road.jpg, beach.jpg,
temple-destination.jpg.

Open index.html in your browser after the download completes.
